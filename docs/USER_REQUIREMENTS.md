# 프로젝트명: 경제의 실체 (Economic Reality)

## 1. 프로젝트 목표

너는 거시경제학자, 금융시장 분석가, 산업경제 연구원, 데이터 분석가이자 소프트웨어 엔지니어다.

현재 대한민국과 세계경제의 실제 상태를 객관적으로 분석할 수 있는 데이터 기반 경제분석 시스템을 구축하라.

이 프로젝트의 목적은 단순한 경제뉴스 요약이나 경제지표 나열이 아니다.

**경제가 실제로 성장하고 있는지, 성장의 성과가 누구에게 돌아가는지, 현재 경제가 어떤 위험을 가지고 있으며 앞으로 어떤 방향으로 움직일 가능성이 있는지를 객관적으로 판단하는 것**이다.

특정 정치적 입장이나 언론의 논조에 영향을 받지 말고 검증 가능한 경제통계와 경제학적 분석에 기초하여 결론을 도출하라.

최종 결과물은 다음 세 가지 기능을 갖춰야 한다.

1. 한국과 세계경제의 현재 상태를 심층 분석하는 보고서
2. 경제지표를 시각화하고 추세를 비교하는 대시보드
3. 새로운 경제통계가 발표되면 분석을 업데이트할 수 있는 데이터 관리 구조

# 2. 분석의 기본 원칙

다음 원칙을 반드시 준수하라.

### 2.1 객관성

- 긍정적 지표와 부정적 지표를 모두 분석한다.
- 경제성장과 국민의 체감경기를 구분한다.
- 단기 경기변동과 장기 구조적 변화를 구분한다.
- 통계적 상관관계와 인과관계를 혼동하지 않는다.
- 특정 경제정책의 효과를 평가할 때 반대되는 근거도 함께 제시한다.

### 2.2 정확성

- 모든 수치에 통계 출처와 기준 시점을 명시한다.
- 가능한 한 정부 및 공신력 있는 국제기구의 공식 통계를 사용한다.
- 최신 자료가 확인되지 않으면 과거 자료를 최신 자료처럼 제시하지 않는다.
- 확인할 수 없는 수치는 추정하거나 만들어내지 않는다.
- 자료가 불충분하면 반드시 '추가 검증 필요'라고 표시한다.
- 속보치, 잠정치, 확정치를 구분한다.

### 2.3 분석의 깊이

단순히 지표의 상승과 하락을 설명하는 데 그치지 말고 다음 질문에 답하라.

- 왜 이러한 변화가 발생했는가?
- 변화의 구조적 원인은 무엇인가?
- 어떤 경제주체가 이익을 얻는가?
- 어떤 경제주체가 불이익을 받는가?
- 다른 경제지표에 어떤 영향을 미치는가?
- 이러한 변화가 지속될 가능성은 얼마나 되는가?
- 향후 경제에 어떤 위험이나 기회가 발생할 수 있는가?

8. 계절조정 여부를 표시한다.
9. 수집 실패와 결측값을 기록한다.
10. 공식 자료가 없는 경우 대체자료의 한계를 명시한다.

API 키가 필요한 경우 환경변수로 관리하라.

실제 데이터를 수집하지 못한 경우 임의의 숫자로 대체하지 말 것.

# 5. 데이터 분석 방법

다음 분석을 수행하라.

### 5.1 시계열 분석

- 최근 1년
- 최근 3년
- 최근 5년
- 최근 10년

각 기간의 추세와 변곡점을 분석한다.

### 5.2 지표 간 관계 분석

다음 관계를 검토하라.

- 경제성장률과 고용률
- 물가상승률과 실질임금
- 금리와 민간소비
- 금리와 부동산가격
- 수출 증가율과 제조업 고용
- 기업이익과 임금
- 가계부채와 소비
- 환율과 수입물가
- 생산성과 실질임금

단순 상관관계를 인과관계로 단정하지 말고, 경제이론과 시차 및 교란변수를 함께 검토하라.

### 5.3 경기국면 분석

현재 경제를 다음 네 단계 중 어느 국면에 가까운지 분석하라.

1. 확장
2. 둔화
3. 침체
4. 회복

단일 지표로 판단하지 말고 복수의 지표를 사용하라.

판정 기준과 판단의 불확실성을 설명하라.

공식 경기순환 기준일이 발표되지 않았다면 자체 추정과 공식 판정을 명확히 구분하라.

### 5.4 위험 분석

다음 위험을 검토하라.

- 경기침체
- 물가 재상승
- 금융불안
- 가계부채 부실
- 부동산시장 불안
- 수출 둔화
- 산업경쟁력 약화
- 고용시장 악화
- 글로벌 금융 충격

각 위험에 대해 다음을 제시하라.

- 발생 원인
- 현재 관측되는 위험 신호
- 위험을 완화하는 요인
- 경제에 미칠 영향
- 지속해서 관찰해야 할 지표

# 6. 미래경제 전망

향후 전망은 다음 기간으로 구분한다.

- 향후 3개월
- 향후 6개월
- 향후 1년
- 향후 3년
- 향후 5년

세 가지 시나리오를 작성한다.

### 낙관적 시나리오

경제성장이 예상보다 빠르게 개선되는 경우.

### 기준 시나리오

현재 확인 가능한 경제정보를 바탕으로 가장 개연성이 높은 경우.

### 비관적 시나리오

주요 위험요인이 현실화되는 경우.

각 시나리오에는 다음을 포함한다.

- 발생 조건
- 경제성장 방향
- 고용 변화
- 물가 변화
- 금리 및 금융시장 영향
- 산업별 영향
- 시나리오를 검증할 핵심 지표

정량적 전망을 제시할 경우 반드시 모형, 가정, 데이터 근거를 공개하라.

객관적인 확률을 산정할 근거가 없는 경우 임의로 확률을 부여하지 말 것.

# 9. 지속적인 업데이트 구조

이 프로젝트는 일회성 보고서가 아니라 지속적으로 활용할 경제분석 시스템이다.

따라서 다음 기능을 구현하라.

- 새로운 공식 통계 발표 여부 확인
- 신규 데이터 수집
- 기존 데이터와 비교
- 변화가 큰 지표 식별
- 분석 결과 갱신
- 이전 보고서와 최신 보고서 비교
- 데이터 수집 및 분석 이력 보관

자동화가 어려운 경우 수동으로 업데이트할 수 있는 명령어와 실행 방법을 제공하라.

기존 데이터를 삭제하거나 덮어쓰지 말고 가능한 한 변경 이력을 관리하라.

# 11. 작업 수행 지침

먼저 현재 작업 폴더와 개발환경을 확인하라.

기존 파일이 있다면 임의로 삭제하거나 변경하지 말 것.

프로젝트의 디렉터리 구조를 설계하고, 필요한 파일을 생성하라.

실제 데이터 수집과 검증을 우선 수행하고, 확인된 데이터를 기반으로 분석 기능을 개발하라.

복잡한 작업은 단계별로 나누되, 단순한 계획 수립에서 멈추지 말고 실행 가능한 결과물을 구현하라.

외부 API나 네트워크 접근이 제한되는 경우 해당 원인을 기록하고, 가능한 범위의 기능을 완성하라.

별도의 승인이 필요한 유료 서비스는 사용하지 말 것.

모든 사용자 인터페이스, 보고서, 그래프 제목, 설명은 한국어로 작성하라.

**최종 목표는 경제뉴스를 읽고 판단하는 프로그램이 아니라, 데이터를 근거로 현재 경제의 상태와 위험을 스스로 검증할 수 있는 경제분석 시스템을 구축하는 것이다.**
