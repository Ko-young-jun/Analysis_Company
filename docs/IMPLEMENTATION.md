# 경제의 실체 구현 계약

- Python 3.12, Pandas, Plotly, Streamlit, SQLite. 기존 빈 저장소에서 사용자 요구에 따라 구현한다.
- 8개 분석 영역을 카탈로그와 수집 가능 범위 표에 유지한다. 공개 World Bank WDI 연간 통계와 FRED 공개 CSV부터 수집한다. 국내 세부 통계는 검증된 공식 CSV 가져오기를 지원한다.
- 데이터가 없으면 값, 결론, 경기국면, 전망 확률을 생성하지 않는다. 수집 실패와 미구현 지표를 공개한다.
- 원문 응답은 해시를 붙여 보관하고, 시점별 관측값 버전을 추가한다. 기준기간·수집시각·발표일·공급자 갱신일은 서로 다른 필드다. 모르는 발표일/확정 여부는 미확인이다.
- 같은 지표·국가·기간의 개정값을 보존하며 최신 버전 조회와 과거 실행시점 조회를 지원한다. 결측 공표도 하나의 버전으로 보존한다.
- 화면, 다운로드, 보고서는 동일 DB 조회와 계산 함수를 사용한다.
- 1/3/5/10년 추세, 국가 비교, 지표 관계, 변동 감지, 데이터 커버리지 및 보고서 이력 제공.
- 자동 갱신은 명령으로 제공하며 외부 스케줄링/배포/유료 사용/환경 게시를 수행하지 않는다.

검증 경계: 네트워크 어댑터의 파싱, 저장소의 개정 및 원자성, 달력 기준 변화 계산, 비교기간/단위 호환, 빈 데이터의 정직한 표시, 앱 실행과 실제 API 접근을 각각 검증한다. 테스트용 수치는 운영 DB에 쓰지 않는다.
