# 경제의 실체 (Economic Reality)

한국과 세계경제를 공식 시계열로 비교하고 수집·개정·보고서 이력을 보존하는 한국어 분석 시스템입니다.

## Vercel 웹 버전

브라우저 배포용 Vite·Node 서버리스 웹 버전을 추가했습니다. [Vercel 배포 안내](docs/VERCEL.md)를 참고하세요. 웹은 공식 자료 조회·국가 비교·CSV/HTML 다운로드를 지원하고, 아래 Python 프로그램은 개정 이력 보관과 전체 보고서 생성에 사용합니다.

## 현재 상태

**소프트웨어는 구현했지만 실제 공식 통계 수집은 이 클라우드 환경의 도메인 차단으로 실패했습니다. 최신 경제분석이 완성된 상태가 아닙니다.**

- World Bank WDI 33개 지표 × 한국·미국·중국·일본·EU·유로지역·세계, FRED 9개 지표의 수집 경로를 구현했습니다. 공급자 응답 형식 테스트를 통과했으며 실제 API 스키마와 시리즈 가용성은 접근 복구 후 확인해야 합니다.
- 최초 수집 실행: 출처별 첫 요청 2건 실패, 같은 출처의 나머지 40건 미시도. 실제 관측값 0건. 합성 데이터를 운영 DB에 넣지 않았습니다.
- 8개 화면: 현황, 지표 탐색, 국가 비교, 시차 관계, 산업·청년고용, 변화 감지·조건부 시나리오, 수집·개정 이력, 보고서.
- 한국의 월·분기 지표, 실질임금, 부동산·PF, 세부 산업·자산분포 등은 미확보입니다. `economic_reality/catalog.py`의 `GAPS`와 화면에서 범위를 확인할 수 있습니다.
- 경기국면 자동 판정, 정량 전망, 개별 정책·AI의 인과효과는 아직 구현/검증되지 않았습니다. 보고서는 확인된 사실과 해석 틀을 구분하며 데이터가 없으면 수집 상태 보고서만 생성합니다.
- 외부 배포, 환경 게시, 유료 서비스 사용, 정기 작업 등록은 하지 않았습니다.

## 시작

Python 3.12 권장. 클라우드 환경에서는 다음 명령을 실행합니다.

```bash
cd /workspace/Analysis_Company
bash scripts/install.sh
bash scripts/start.sh
```

다른 컴퓨터에서는 프로젝트 폴더에서 다음과 같이 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m streamlit run app.py
```

Streamlit은 기본적으로 8501 포트를 사용합니다. 클라우드 온보딩 화면에서는 외부 미리보기 링크를 제공하지 않습니다. 상시 외부 접속이 필요하면 별도 배포 작업이 필요합니다.

## 공식 자료 수집·갱신

```bash
cd /workspace/Analysis_Company
.venv/bin/python -m economic_reality update
.venv/bin/python -m economic_reality status
.venv/bin/python -m economic_reality export
.venv/bin/python -m economic_reality report
# 수집 → 내보내기 → 보고서 (실패 시에도 상태 보고서를 생성하고 종료 코드 유지)
bash scripts/refresh.sh
# 한 출처 또는 지표만 재검증
.venv/bin/python -m economic_reality update --source worldbank --only wb:NY.GDP.MKTP.KD.ZG
```

수집은 기본 2015년부터 실행 시점 연도까지 요청합니다. `--start 2010`으로 늘릴 수 있습니다. 일부 출처 실패/무자료이면 종료 코드 2입니다. 수집 명령은 원 데이터와 이전 보고서를 삭제하지 않습니다. 네트워크 거부가 확인된 출처는 같은 실행에서 반복 호출하지 않습니다.

### 현재 필요한 네트워크 설정

실제로 사용하는 수집 경로는 다음 두 HTTPS 도메인입니다.

- `api.worldbank.org` — WDI API, 인증키 불필요
- `fred.stlouisfed.org` — 공식 공개 CSV, 현재 구현 경로는 인증키 불필요

확장할 공식 출처 도메인도 환경 초안에 추가했지만 저장만으로 현재 런타임에 적용되지는 않습니다. 환경 설정에서 네트워크 변경을 저장한 뒤 위 수집 명령으로 검증해야 합니다. TLS 검증을 끄거나 차단 정책을 우회하지 마세요.

ECOS/KOSIS 등 키가 필요한 커넥터는 아직 연결하지 않았습니다. 필요한 경우 환경의 보안 설정을 통해 키를 등록해야 하며 코드·CSV·Git·채팅에 키를 기록하지 않습니다.

## 공식 CSV 가져오기

공식 다운로드 자료를 다음 열로 정규화합니다. 숫자가 없는 관측값은 빈칸입니다. 임의의 숫자를 만들지 마세요.

```csv
country,period,value,release_date,status
```

- 국가: `KOR, USA, CHN, JPN, EUU, EMU, WLD`
- 기준기간: 연 `2025`, 분기 `2025Q1`, 월 `2025-01`, 일 `2025-01-01`
- 상태: `속보치`, `잠정치`, `확정치`, `미확인`
- 발표일: 확인된 실제 발표일 ISO 날짜. 모르면 빈칸.

같은 자료에 대해 메타데이터 JSON을 작성합니다. 아래는 구조 예시이며 관측 데이터가 아닙니다. `source_url`에는 실제 공식 다운로드 원문 주소를 입력하세요.

```json
{
  "id": "local:verified-series-name",
  "name": "실제 지표명",
  "category": "물가와 실질구매력",
  "unit": "실제 단위",
  "frequency": "M",
  "source": "실제 공식 생산기관",
  "source_url": "https://공식기관의-실제-원문-주소",
  "adjustment": "비계절조정",
  "price_basis": "명목",
  "note": "모집단·기준연도·공표 주기와 비교 유의점"
}
```

```bash
.venv/bin/python -m economic_reality import-csv /path/to/official.csv /path/to/metadata.json
```

수동 가져오기 기능은 출처의 공식성을 자동 보증하지 않습니다. URL과 통계 정의를 확인해야 합니다. 동일 ID의 단위·주기·가격/계절조정 기준이 바뀌면 새로운 ID를 사용해야 합니다.

## 저장과 재현

- `data/raw/`: SHA-256 파일명의 원문. 동일 원문은 재사용하고 개정 원문은 별도 파일로 보관.
- `data/economy.sqlite3`: 지표 정의, 수집 실행, 성공/실패 로그, 국가·기간·실행별 관측값.
- `data/exports/`: 시각별 정제 CSV와 메타데이터 JSON.
- `reports/<한국시간>/`: 보고서 Markdown, PNG 그래프, 근거 CSV, 수집 로그, 커버리지, manifest, 이전 보고서와 diff.
- 운영 데이터·가상환경·보고서는 Git에서 제외합니다. 소스만 Git으로 관리됩니다. 지속 운영에서는 `data/`와 `reports/`를 별도로 백업해야 합니다.

기존 수치를 개정값으로 덮어쓰지 않습니다. 공표가 결측으로 바뀐 경우도 버전으로 기록합니다. 사이드바에서 수집 실행을 선택해 관측값의 과거 버전을 볼 수 있습니다. 수집 이전의 원래 발표 당시 자료를 복원하는 기능은 아닙니다. 화면·보고서의 의미를 바꾸는 지표 정의 수정에는 새 ID를 사용하세요.

## 분석 원칙과 제한

- 수집일, 기준기간, 실제 발표일, 공급자 갱신일을 별도 관리합니다. WDI `lastupdated`는 개별 관측의 발표일이 아닙니다. CSV에 발표일/잠정·확정 상태가 없으면 미확인입니다.
- API에 최신 자료가 있다고 가정하지 않습니다. 지표별 기준기간을 표시하고, 서로 다른 연도의 값을 동일 시점 비교로 해석하지 않습니다.
- 연간 자료로 현재 월별 경기국면을 추정하지 않습니다. 민간신용을 가계부채로, GDP를 임금으로, 제조업 합계를 반도체 성과로 대신하지 않습니다.
- 국제 청년은 15~24세 ILO 추정입니다. 한국 청년통계의 연령 정의와 다릅니다.
- 같은 달력 기준기간을 비교합니다. 결측을 전방 채움하거나 0으로 치환하지 않습니다. 비율 차이는 %p입니다.
- 지표 관계는 동일 주기·계절조정 자료의 1차 차분을 비교합니다. 시차 상관은 인과 추정이 아니며 최소 12개의 일치하는 변화가 필요합니다.
- 변동 감지는 이전 최대 36개 변화의 평균과 표준편차를 사용합니다. 최소 8개 변화가 필요하며 2 표준편차 이상이면 표시합니다. 경제위기 확률이나 투자 판단을 뜻하지 않습니다.
- 보고서와 수집 상태 화면은 DB 전체의 최신 버전입니다. 탐색 화면의 국가·기간·과거 시점 필터와 범위가 다름을 화면에 표시합니다.
- 시나리오는 3개월·6개월·1년·3년·5년의 조건부 점검 틀입니다. 자료 검증 전에는 현재 전망이나 객관적 확률로 제시하지 않습니다.
